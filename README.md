# MétricaLab — projeto de estudo

Página demonstrativa em HTML, CSS e JavaScript para estudo de métricas, eventos e consentimento de cookies.

## Executar
Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Recursos
- Layout responsivo.
- Painel de consentimento com opções de métricas e marketing.
- Preferências salvas no navegador.
- Evento demonstrativo para cliques e formulário.
- Integrações HubSpot/Awin desativadas por padrão.

## Integrações
Os identificadores nos arquivos enviados são de terceiros. Antes de ativar integrações, confirme que as contas pertencem à sua organização e revise privacidade e consentimento. O script Awin enviado inclui fingerprinting; avalie cuidadosamente antes de qualquer uso. Esta demonstração não é uma certificação LGPD.

O formulário é apenas demonstrativo: nenhum dado é transmitido.
